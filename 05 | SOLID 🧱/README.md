# SOLID 🧱
- Os princípios SOLID são um conjunto de diretrizes de design de software que visam criar código mais legível, flexível e fácil de manter.
- Eles foram introduzidos por Robert C. Martin e representam um guia para a criação de sistemas orientados a objetos bem estruturados.

### 1. Princípio da Responsabilidade Única (SRP)

- Cada classe deve ter apenas uma razão para mudar.
- Uma classe deve ter apenas uma responsabilidade.
- Isso promove a coesão e facilita a manutenção, já que cada classe trata de uma única preocupação.

### 2. Princípio Aberto/Fechado (OCP)

- Entidades de software (classes, módulos, etc.) devem estar abertas para extensão, mas fechadas para modificação.
- Novos comportamentos podem ser adicionados sem alterar o código existente.
- Isso facilita a expansão do sistema sem impactar seu funcionamento atual.

### 3. Princípio da Substituição de Liskov (LSP)

- Subtipos devem ser substituíveis por seus tipos base sem afetar a corretude do programa.
- A herança deve manter a semântica dos tipos, preservando as propriedades esperadas.
- Isso assegura que a substituição de objetos não cause comportamentos inesperados.

### 4. Princípio da Segregação de Interfaces (ISP)

- As interfaces devem ser específicas para os clientes que as utilizam.
- Evita a criação de interfaces volumosas com métodos que não são relevantes para todos os clientes.
- Isso promove a coesão e evita dependências desnecessárias.

### 5. Princípio da Inversão de Dependência (DIP)

- Módulos de alto nível não devem depender de módulos de baixo nível. Ambos devem depender de abstrações.
- Abstrações não devem depender de detalhes; detalhes devem depender de abstrações.
- Isso promove a flexibilidade, reutilização e facilita a troca de implementações.

### Vantagens dos Princípios SOLID:

- Código mais modular, flexível e fácil de manter.
- Redução do acoplamento entre componentes.
- Facilita a reutilização de código.
- Melhora a testabilidade e escalabilidade do software.
- Promove boas práticas de design orientado a objetos.

### Utilização dos Princípios SOLID:

Os princípios SOLID devem ser aplicados durante o processo de design e desenvolvimento de software. Eles ajudam a criar sistemas mais robustos e adaptáveis, facilitando a evolução do código ao longo do tempo.

### Conclusão:

Os princípios SOLID fornecem um guia valioso para o design de software orientado a objetos, promovendo a criação de sistemas bem estruturados e de alta qualidade.
